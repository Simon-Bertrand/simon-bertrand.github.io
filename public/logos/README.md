# Sources des logos

Les PNG existants sont conservés. Leur présentation dans les thèmes clair et sombre est gérée en CSS.

- `ArmeeAirEspace.svg` : logo de l’Armée de l’Air et de l’Espace, vectorisation par Dorian crd, provenant de [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Logo_de_l%27Arm%C3%A9e_de_l%27Air_et_de_l%27Espace.svg). La fiche cite le dossier de presse du ministère des Armées comme source et classe le dessin dans le domaine public (`PD-textlogo`).
